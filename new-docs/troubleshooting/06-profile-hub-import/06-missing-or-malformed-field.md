# Profile import fails because a field is missing or malformed

**Applies to:** MCP Profile Hub

The app shows the heading `Couldn't import profile`, then the message below:

```
That profile is missing or malformed at "profile.name".
```

**Root cause**

A required field is absent, or it holds the wrong type of value. The message names the field.

**Resolution**

Export the profile again instead of editing the file by hand.
