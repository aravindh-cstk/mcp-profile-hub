# Profile import fails because the organization reached its profile limit

**Applies to:** MCP Profile Hub

The app shows the heading `Couldn't import profile`, then the message below:

```
Organization profile limit of 500 reached; ask an administrator to remove unused profiles
```

**Root cause**

Your organization already holds the maximum of 500 profiles.

**Resolution**

Ask an organization admin to remove unused profiles, then import the file again.
