# An automation call fails because the automation is not active

**Applies to:** MCP Profile Hub

The error message contains `is not activated in Contentstack Automate, so it did not run`.

**Root cause**

The automation is still a draft, or someone paused it.

**Resolution**

Open the automation in Automate and activate it. The [What qualifies](/docs/developers/mcp-profile-hub-automations-and-agents#what-qualifies) section lists every condition an automation must meet to work as a tool.
