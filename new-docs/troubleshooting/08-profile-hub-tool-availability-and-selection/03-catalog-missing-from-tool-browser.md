# A catalog is missing from the tool browser

**Applies to:** MCP Profile Hub

**Root cause**

Your organization's plan does not include that product, so the tool browser does not display its tab or its tools.

**Resolution**

1. Ask your organization's Contentstack admin to confirm the plan.
2. Contact [Contentstack support](mailto:support@contentstack.com) to add the product. Until then, build the profile from the catalogs your plan includes.
