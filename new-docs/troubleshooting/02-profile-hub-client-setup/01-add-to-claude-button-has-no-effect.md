# The Add to Claude button has no effect

**Applies to:** MCP Profile Hub, Claude Desktop tab

**Root cause**

Your Claude plan restricts custom connectors to organization admins.

**Resolution**

Use the **Claude Desktop Manual** installation tab instead, or ask a Claude organization admin to add the connector.

> **Additional Resource:** For more information on each installation tab, refer to the [Connect a client to MCP Profile Hub](/docs/developers/mcp-profile-hub-connect-a-client-to-profile-hub) documentation.
